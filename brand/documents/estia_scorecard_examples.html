計分卡逐條範例

每一條:定義 → ✓ 怎樣算滿足 → ✗ 怎樣算不滿足

基線年原則:成果層三指標(續租/回訪/推薦),第一年只量、不設及格線——沒有真實數據前訂的線都是猜的。第一年量出基線,第二年的目標=基線+進步幅度。門檻層(資格審查)則第一年就生效——那些是「說到做到」,不需要等數據。

門檻層 · 個人過/不過 · 過了才有資格分獎金 · 不算分數

G1儀式出席 ≥ 8 成
全年細節圈約 26 場 + 爐邊會 12 場 ≈ 38 場;8 成 ≈ 30 場。請假照算缺席,但長假(產假/長病假)期間從分母扣除。
✓

小芳全年出席 33 場:缺 3 場是排休帶看撞期、1 場病假 → 33/38 = 87%,過。缺席有原因不用解釋文件,達標就是達標。

✗

某人出席 24 場 (63%),缺席常態是「太忙,這次先跳過」→ 不過。忙不是理由——儀式排在工作時間內,跳過是選擇。

G2年度輪班完成
每人每年:2 天接待 + 1 天房務 + 住一晚(補課年)。含 Jim 本人。
✓

會計行政 3 月排了房務日、7 月跟了兩天接待、9 月完成住一晚 → 過,年底不用趕。

✗

到 12 月房務日還在「下個月再排」,最後沒排成 → 不過。這條沒有補考——它量的不是勞動,是「有沒有把這件事當真」。

G3零誠信事件 —— 錯誤免責,隱瞞重罪
做錯事永遠不影響這條;隱瞞、說謊才觸發。認定需經當面談(修復劇本 Station 1 流程),不片面裁定。
✓

美玲補備品漏了一間的水,隔天自己發現、自己在細節圈講、順手提議在備品清單加勾稽欄 → 完全沒事,而且這正是我們要的自首文化。錯誤進流程檢討,人不進黑名單。

✗

打掃時碰倒檯燈裂了底座,轉個角度藏起來沒報;客人退房點交發現,問到第二次才承認 → 誠信事件,當年門檻不過。罰的不是打破燈的手,是遮起來的手。

門檻層 · 團隊全隊一起過/不過 · 影響團隊份獎金

G412 小時首覆達成率 ≥ 95%
全年所有詢問,12 小時內完成首覆的比例。不設 100%——一次半夜的系統漏接不該毀掉全年,但 95% 以下代表流程有洞。
✓

全年詢問 214 件,12 小時內首覆 208 件 = 97.2%,過。漏的 6 件都有事後補救紀錄。

✗

達成率 89%——追蹤表一看,漏的集中在連假和值日交接日 → 不過 → 團隊複盤值日制度哪裡斷線,團隊份受影響。檢討的是排班設計,不點名個人。

G5押金 14 天退還
全年退房案件,14 天內退還+附明細。允許至多 1 件例外,且需書面原因(件數少,一件失手就掉好幾個百分點,絕對條款比比例合理)。
✓

全年 18 件退房,17 件 14 天內退畢;1 件因房東端水電結算延遲,第 16 天退,台帳上有原因紀錄、有先行通知客人 → 過。

✗

3 件超過 14 天,台帳沒寫原因,其中 1 件客人來信催 → 不過。款待的最後一棒掉在地上,而且掉了沒人記錄。

G6平台評分地板
全年平台平均分 ≥ 地板值。地板=現況微降(示意:現況 4.8 → 地板 4.7,正式值待 Jim 提供現況)。星等是防線不是比賽:只防崩壞,不獎討好。
✓

年終結算平台平均 4.82,高於地板 → 過。就這樣,沒有「4.9 多發錢」——星星不進加分。

✗

平均掉到 4.55,破地板 → 不過 → 團隊複盤:掉分評語集中在哪(清潔? 回覆? 設備?),修系統。另一種不滿足:任何人對客人說出「方便幫我們留五星嗎」——這句話本身就違規,無論星數多高。

成果層 · 三指標決定池子怎麼分 · 第一年量基線

R1續租率(含延住)
分母=年內租約到期的租約數;分子=其中選擇續租或延住 ≥1 個月的。
✓

全年到期 20 份,續租 9 份 → 續租率 45%。第一年:45% 就是基線,寫進紀錄。第二年目標訂 45%+5pp=50%,實際 51% → 達標。

✗

第二年實際 38%,低於基線 → 未達 → 複盤:退租原因逐案記錄了嗎? 是價格、是服務、還是客人任期本來就到了(外派結束回國不算流失,分母應剔除「任期自然結束」案件——定義要先講清楚,不然指標冤枉人)。

R2回訪率
分母=去年度離開的客人數;分子=其中 12 個月內回來再住(任一物件)的人數。靠客人檔案追蹤。
✓

去年離開 30 位,今年回來住的 4 位 → 回訪率 13%=基線。這個指標天生偏低(客人要再來台北才可能回訪),低不代表差,趨勢才是重點。

✗

回訪 0 位,且離開後訊息(Day 17 第⑦封)全年只發了 3 封——不是客人不回來,是我們沒把門留著。指標揪出的是動作沒做,不是運氣不好。

R3推薦率
分母=年度新簽約數;分子=來源為「舊客/房東介紹」者。來源在首覆時固定問一句「怎麼認識我們的」,記入追蹤表來源欄。
✓

新約 25 份,其中 6 份是舊客介紹(David 介紹了他同事來住松山)→ 推薦率 24%=基線。

✗

追蹤表來源欄一半空白 → 這一年指標作廢重來——沒記錄的數據不能拿來發錢。不滿足的第一種形式,永遠是「沒好好記」。

池子 · 營業額決定池子多大 · 不進個人公式

¥雙籃比較法
池子=當年實際總營業額 × 提撥率(絕對值,新舊物件自動涵蓋)。「做得好不好」另外看,分兩籃,是 Jim 的儀表板,不進員工公式。
✓

同店籃:仁愛+松山去年 3,600 萬 → 今年 3,850 萬,同店 +6.9%。長租滿租後天花板固定,成長只能來自續租墊高、空窗縮短、合理調租——+3~5% 即健康,市場冷年持平不丟臉。

✓

新店籃:八德開站前,Jim 白紙黑字寫下第一年目標 480 萬 → 實際 512 萬 = 達成率 107%。

✗

開封實際 430 萬 = 90% 未達 → 檢討的是定價與定位(老闆的功課),不砍員工獎金——新店的風險在老闆身上;池子用實際營業額,已自動如實反映。另一種不滿足:開站後才回頭補寫目標——事後諸葛的目標不算目標。

日常服務標準她的骨架改寫 · 是尺不是分 · 不進獎金

S1住客訊息回覆階梯(保留她的 5/15/30 分鐘)
在住客人的日常訊息:5 分鐘內=優,15 分鐘內=正常,30 分鐘未回=需補救。這是尺,不是分——超過 30 分鐘的動作是「補一句致歉+處理」,不是被扣分。
✓

David 10:02 問洗衣機怎麼用,雅婷 10:09 回覆+附一張標籤照片 → 正常範圍,還快了半步。

✗

訊息 3 小時沒人回,因為負責 Host 在帶看、又沒交接 → 不是扣她分,是細節圈上檢討「帶看時段誰接手機」的交接洞。尺量出來的洞,用流程補。

公平條款 · 免得制度冤枉人
  • 長假調整 — 產假/長病假期間,出席與輪班門檻的分母按實際在職期間折算。
  • 新人折算 — 到職未滿一年,年終按在職月數比例;門檻同樣按比例。
  • 誠信事件正當程序 — 需經當面對談與紀錄,不憑單方說法;當事人有完整陳述機會。
  • 定義先行 — 每個指標的分母分子(如「任期自然結束不算流失」)在年初白紙黑字,年中不改規則。
  • 數據缺漏 — 沒被記錄的表現不能拿來發錢,也不能拿來扣錢;記錄本身是團隊的共同責任。
